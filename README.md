## 1-3. 核心の発見 — 「紹介」が全ての鍵

ベトナムのビジネス文化は関係性・面子（thể diện）を重視する。最上位の会員制クラブHaus Private Clubが「既存会員の紹介のみ（chỉ những người được giới thiệu bởi hội viên hiện tại）」で入会を絞る構造が、紹介が富裕層アクセスの門番であることを象徴している。

**ゴルフの数字：**
- 経営者の**93%**が「ゴルフはビジネスパートナーとの関係構築の完璧な近道（con đường tắt hoàn hảo）」と回答
- **54%**が商談機会をもたらすと考え、**80%**が新規商談関係の形成に役立つと同意
- 出典：doanhnhansaigon.vn

**外国人がベトナム富裕層にアクセスする実践的手法（優先順）：**

1. **日系ハブを起点にする** — JCCH（1,080社）→ 越側パートナー → その先の富裕層へと紹介を連鎖
2. **ゴルフに持ち込む** — 数時間を共有でき、商談の「完璧な近道」
3. **会食・葉巻・ワインの趣味コミュニティ** — 富裕層の素の姿を観察できる
4. **BNI週例会で紹介ネットワークに入る** — 1業種1名制で経営者と定常接触
5. **プレミアム旅行代理店・プライベートバンクと提携** — 富裕層名簿保有者をB2B2Cのゲートウェイに

> **結論：** 外国人（日本人）がベトナム富裕層に会う最短経路は、JCCHやYBAなどの日系ハブを起点に「暖かい紹介」を得てゴルフ・会食に持ち込むこと。冷たいアウトバウンドやOTA広告は富裕層には効かない。

# Agenda 2. 山口の仮説 — 「どこに行くべきか」への5つの回答

**本パートの目的：リサーチ結果を踏まえ、事業責任者として「自分はこう動く」を5つの仮説として提示する。佐々木氏には優先順位と実行可能性の壁打ちをお願いしたい。**

---

## 仮説1（最優先）：サイゴンツーリスト面談を「紹介の起点」として設計する

**8月面談のゴールを「送客合意」から「紹介ネットワークへの接続」に拡張する**

サイゴンツーリストは単なる送客パートナーではなく、ベトナム最大手旅行会社としての**富裕層顧客ネットワーク**へのゲートウェイ。面談で「まず1-2組テスト送客」を取るだけでなく、彼らの富裕層顧客担当者・VIP部門との接続を獲得することで、紹介の連鎖を仕掛ける。

サイゴンツーリストの看板を借りることで「日本人がいきなり来た」ではなく「サイゴンツーリスト経由で来た人」として信頼のベースラインが上がる。

| 項目 | 内容 |
|------|------|
| **具体アクション** | 8月面談時に「VIP顧客向け京都プライベートツアーの共同企画」を提案。ST側の富裕層担当者を紹介してもらい、直接ヒアリングの機会を取る |
| **検証基準** | 面談後2週間以内にST経由で富裕層本人3名以上のヒアリング機会を獲得できるか |
| **リスク** | STが組織として動くまでに時間がかかる。担当者レベルの興味と経営判断は別 |
| **時間軸** | 8月面談 → 8月中に富裕層ヒアリング3件 |

---

## 仮説2（高優先）：ゴルフを「商談の入口」として使う

**Tân Sơn Nhấtゴルフ場・業界団体ゴルフ会に潜り込み、経営者との関係を直接構築する**

リサーチが示す通り、ゴルフはベトナム富裕層にとって「完璧な近道」。4時間のラウンドで自然に信頼関係を構築でき、商談に直結する。山口自身がゴルフをやるかどうかに関わらず、ゴルフ大会・コンペへの帯同・スポンサー参加は可能。

JCCH経由のゴルフ会、外交親善ゴルフ大会（年次）、YBAのゴルフイベントが具体的な入口。**ゴルフは広告費ゼロで富裕層と数時間同席できる唯一のチャネル。**

| 項目 | 内容 |
|------|------|
| **具体アクション** | JCCH・Kondo氏経由でゴルフ会の日程を確認し、最寄りのイベントに参加。ゴルフ未経験なら練習場（Him Lam Golf）に通い始める |
| **検証基準** | ゴルフ経由で富裕層経営者5名以上と名刺交換し、うち2名以上と会食に発展するか |
| **リスク** | ゴルフ経験がない場合、関係構築に時間がかかる。コンペ参加だけでは浅い接触に留まる可能性 |
| **時間軸** | 8月中にゴルフ会1回参加 → 9月末までに経営者5名との接点確立 |

---

## 仮説3（高優先）：プレミアム旅行代理店を「競合ヒアリング先」兼「提携候補」として攻める

**NhatbanAZ・Top Ten Travelから富裕層の実像を一次情報で取る**

NhatbanAZ（高級専用車・専属ガイド・一流料亭の日本ツアー）やTop Ten Travel（オーダーメイド家族旅行）は、**今まさにベトナム富裕層に日本ツアーを売っている**。彼らが持っている一次情報——顧客の年齢層・予算感・京都への関心度・満足点と不満点——は、どんなデスクリサーチよりも価値が高い。

競合だが敵ではない。京都プライベートツアーに特化した「現地パートナー」として提携する余地がある。

| 項目 | 内容 |
|------|------|
| **具体アクション** | NhatbanAZ・Top Ten Travel・Du Lịch Việtに「京都の現地パートナー」としてコンタクト。彼らの京都ツアーの現状と課題をヒアリング |
| **検証基準** | 2社以上から「京都に信頼できる現地パートナーが欲しい」というニーズが確認できるか |
| **リスク** | 競合視されて情報を出してもらえない可能性。ただし「京都現地」という棲み分けを提示すれば協業は成立しうる |
| **時間軸** | 8月中にコンタクト → 9月中にヒアリング2社完了 |

---

## 仮説4（中優先）：BNIホーチミンのチャプターに参加し、「紹介の仕組み」そのものに乗る

**1業種1名の排他制を活用して「京都プライベートツアー」枠を押さえる**

BNIは「構造化された紹介」の仕組み。ホーチミンに40超チャプター・2,000人超が所属し、初回見学は無料。1業種1名の排他制があるため、「京都プライベートツアー」というカテゴリで入れば、そのチャプターの全メンバー（経営者層）から独占的に紹介を受けられる。

週例会で毎週経営者と接触でき、紹介文化そのものがビジネスモデル。**広告予算ゼロで、紹介を「仕組み化」できる唯一のチャネル。**

| 項目 | 内容 |
|------|------|
| **具体アクション** | BNI Vietnamの富裕層メンバーが多いチャプター（1区・Thảo Điền周辺）を特定し、初回無料見学に参加 |
| **検証基準** | 見学後1ヶ月以内に「京都プライベートツアー」への紹介リクエストが3件以上出るか |
| **リスク** | 年会費がかかる（要確認）。チャプターによってメンバーの質にばらつき。毎週出席の時間的コミットメントが必要 |
| **時間軸** | 9月に見学 → 10月に正式加入 → 11月以降に紹介経由の案件化 |

---

## 仮説5（中優先）：Thảo Điền（旧2区）の高級飲食・ワインコミュニティに顔を出し、富裕層の「素の姿」を観察する

**Mad Wine・CLAY等を定期巡回し、関係構築の下地を作る**

Thảo Điềnは「富豪の街（khu nhà giàu）」と呼ばれ、外国人富裕層・ベトナム人富裕層が集住するエリア。ここの高級レストラン・ワインバー（Mad Wine、CLAY、La Cave de Saigon等）は富裕層の日常動線上にある。

商談の場ではなく、**富裕層が普段どんな暮らしをし、何にお金を使い、どんな旅行に興味があるかを「観察」する場**。直接営業ではなく、関係構築の下地を作る。仮説1-4が「攻め」なら、これは「情報収集と地盤固め」。

| 項目 | 内容 |
|------|------|
| **具体アクション** | Thảo Điền地区のワインバー・レストランを月2-3回巡回。常連化して自然な会話から京都旅行の関心度を探る |
| **検証基準** | 3ヶ月以内に富裕層居住者5名以上と顔見知りになり、うち2名以上が「京都に行きたい」と自発的に言及するか |
| **リスク** | 時間がかかる。成果が読めない。飲食費がかさむ。ただしコストは月5-10万円程度で、失敗しても情報は残る |
| **時間軸** | 8月開始 → 10月末までに初期の関係構築完了 |

## 5つの仮説の位置づけ — ポートフォリオ設計

| 仮説 | 性質 | 時間軸 | 期待リターン | コスト |

| **H1: ST面談の拡張** | 攻め（組織的） | 即時（8月） | 大 | 低（面談は既定） |
